## FAQ

<details>
<summary><b>How do I change the default primary theme color?</b></summary>
<br>
Modify the <code>--primary-color</code> hex code inside <code>assets/css/style.css</code>. It automatically cascades across all subpages.
</details>

<br>

<details>
<summary><b>Does this template require Node.js or npm to run?</b></summary>
<br>
No. It uses standard client-side technologies and can be served directly from any web browser or simple file host.
</details>

<br>

<details>
<summary><b>Can I connect the contact form to a live email inbox?</b></summary>
<br>
Yes. You can attach a service like Formspree, Web3Forms, or EmailJS inside <code>assets/js/validation.js</code> by replacing the mock success alert handler with an <code>async fetch()</code> post request.
</details>
